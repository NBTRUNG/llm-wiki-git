# LLM-Wiki

LLM-Wiki is a Markdown knowledge and operating vault for AI-assisted work. It
contains reusable workflows, harness guidance, templates, knowledge packs,
architecture concepts, and supporting evidence.

Start with [`index.md`](index.md). Use [`workflows/catalog.md`](workflows/catalog.md)
to select a workflow and [`harness/read-workflow.md`](harness/read-workflow.md)
for the canonical read and source-of-truth rules.

This repository is the Git projection of the working vault. Machine-local
agent configuration, Obsidian state, generated logs, runtime data, and
non-canonical archive material are intentionally excluded.
