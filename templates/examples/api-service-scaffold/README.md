# API service scaffold examples

These files are examples, not global rules.

Use them when a project needs a starter set for API contracts, system design,
infra topology, or data model documentation.

Before use:

- read the project brief;
- check accepted decisions;
- confirm the real repo source of truth;
- remove stack assumptions that do not apply.

## files

- `api-contracts.example.yaml`: OpenAPI starter.
- `system-design.example.md`: architecture outline.
- `infra-topology.example.md`: environment and deployment outline.
- `data-model.example.md`: entity/table outline.
