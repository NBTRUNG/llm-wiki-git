# validation reports

Evidence and review records for LLM-Wiki work units.

## rules

- One report per meaningful work unit, per `program.md §13`.
- Reports are immutable history; do not edit past reports without a strong reason.
- Project status files summarize reports and link here, not the other way around.
- For completed LLM-Wiki durable changes, add the report here and add a concise
  evidence link from `active.md`; do not create `active_archive.md`.
- File name format: `YYYY-MM-DD-<scope-slug>.md`.
