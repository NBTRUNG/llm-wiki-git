# reports

Reports store evidence and reviews that are too detailed for wiki summaries.

## folders

- `validation/`: validation reports for tasks, stories, releases, and reviews.
- `agent/`: delegated agent result reports. These are evidence/history, not the repo-wide status board.

## rules

- Project status should summarize reports and link here.
- Codex/main should review agent reports before rolling accepted state into repo-wide docs.
- Do not paste long command output into wiki pages.
- Use `../logs/test-output/` for long logs.
