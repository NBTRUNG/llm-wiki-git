# Education Platform Concepts

Use this folder for bounded concepts about open-source education platforms and
their possible responsibility boundaries. These are evaluation models, not
adoption decisions or live-system documentation.

## concepts

- [TAO assessment platform](tao-assessment-platform.md): specialist examination
  lifecycle and TAO Community Edition Docker evaluation.
- [ILIAS LMS and training management](ilias-lms-training-management.md): LMS,
  programme/course delivery, progress, and training-administration evaluation.
- [TAO–ILIAS evaluation frame](tao-ilias-evaluation-frame.md): shared test data,
  comparison contract, integration options, and decision gates.

## current decision state

- TAO and ILIAS are candidates under evaluation.
- No final ownership, integration, identity, or deployment architecture is
  accepted yet.
- Docker findings must name edition, version, image origin, plugins, and config.
