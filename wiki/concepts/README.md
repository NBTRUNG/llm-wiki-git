# wiki/concepts

Reusable concepts and patterns live here.

Use concepts for knowledge that applies across projects.

## current concept maps

- `llm-wiki/`: 4-stage lifecycle and visual model for LLM-Wiki operating flow.
- `architecture/`: C4 model, arc42 template, quality attributes, ADR format.
- `security/`: OWASP Top 10 2025, STRIDE, defense in depth, zero trust.

## rules

- Do not turn this folder into a generic textbook.
- Explain how the concept applies in this llm-wiki context.
- Link related decisions and projects.
- Cite raw research when claims come from sources.
