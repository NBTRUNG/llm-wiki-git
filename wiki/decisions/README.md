# wiki/decisions

Compiled decisions and cross-project ADR indexes live here.

Project-level decisions should remain in project source-of-truth docs.

This folder summarizes and links them.

## index

See [[_index.md]] for the table of all filed decisions.

## status values

- `proposed`
- `accepted`
- `superseded`
- `deprecated`
- `rejected`

## rules

- Do not delete old decisions when direction changes.
- Mark old decisions `superseded` and link to the replacement.
- Preserve context, reason, consequences, and review condition.
- Link back to source project decision files.
