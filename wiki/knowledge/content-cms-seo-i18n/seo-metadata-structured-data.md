# SEO, Metadata, And Structured Data

## Checks

- Each important page has a clear title, description, canonical URL, and
  meaningful visible content.
- Robots directives, sitemap, redirects, and canonical tags match the intended
  indexing behavior.
- Structured data uses schema.org types only when the page content supports the
  markup.
- Internal links expose important pages without depending only on search.
- Images/media have useful alt text when they convey content.
- Performance and mobile usability are part of search/user quality.

## Anti-Patterns

- Adding structured data that is not visible or true on the page.
- Letting filters/search results create infinite crawlable URL spaces.
- Changing slugs/routes without redirect and canonical review.
