# Content Migration And Search

## Migration Checks

- Classify content as `preserve`, `script-import`, `rebuild`, or `defer`.
- Map old URL to new URL and redirect behavior.
- Preserve required media, alt text, metadata, publish state, and language
  variants when needed.
- Validate counts, sample pages, broken links, media references, and search
  visibility.
- Separate schema migration from content migration.

## Search Checks

- Define searchable content types and fields.
- Decide freshness, indexing trigger, reindex path, and deletion behavior.
- Keep filters/facets aligned with user workflows.
- Test empty, typo, synonym, multilingual, and permission-sensitive cases.
